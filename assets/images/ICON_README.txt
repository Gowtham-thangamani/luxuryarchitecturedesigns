FAVICON & ICON FILES NEEDED
============================

The following PNG icon files should be generated from the favicon.svg:

1. favicon-16x16.png (16x16 pixels)
2. favicon-32x32.png (32x32 pixels)  
3. apple-touch-icon.png (180x180 pixels)
4. icon-192.png (192x192 pixels) - for Android/PWA
5. icon-512.png (512x512 pixels) - for Android/PWA

You can generate these using:
- Online tool: https://realfavicongenerator.net
- Or use ImageMagick: convert favicon.svg -resize 32x32 favicon-32x32.png

The SVG favicon will work for most modern browsers.
For maximum compatibility, generate the PNG versions.

Brand Colors:
- Gold: #C9A962
- Black: #0A0A0A
- Charcoal: #1A1A1A
